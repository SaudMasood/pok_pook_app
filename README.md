# PakPool Flutter UI

Figma-inspired Flutter UI for the PakPool ride-sharing app.

## Included
- Splash
- Onboarding
- Login / Sign Up
- Forgot Password / Account Confirmation
- Home
- Request Ride
- Create Ride
- My Rides
- Chats
- Profile
- Edit Profile
- Vehicle Information
- Driver Registration
- Saved Places
- Safety Center
- Notification Settings
- Privacy Policy
- Terms & Conditions
- FAQs
- Help & Support
- About Us

## Project structure

```text
lib/
├── main.dart
└── screens/
    ├── common.dart
    └── ...screen files
assets/
└── ...UI assets
```

## Run

```bash
flutter clean
flutter pub get
flutter run
```

The project intentionally keeps the code simple and screen-focused for the internship UI implementation.
